# QuadPlot (クアッドプロット)

## 概要
あらゆる事象やアイディア、感覚を4象限（十字軸）に直感的にマッピングして視覚化するSPAツール。
コーヒーやワインなどの味覚の記録から、タスクの優先度整理、ポジショニングマップの作成など、特定の基準にとらわれず自由に要素をプロットし、全体を俯瞰するためのアプリケーションです。

## 技術スタック
- **Runtime / Package Manager**: Bun
- **Build Tool**: Vite
- **Language**: JavaScript (Vanilla JS)
- **Framework**: Alpine.js
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages (予定)

## 機能
### MVP (現在のスコープ)
- 4象限（十字軸）の固定描画
- 画面クリックによるアイテム（点とラベル）の追加機能
- ドラッグ＆ドロップでのアイテム移動機能
- `localStorage` を利用した状態の自動保存と復元

### バックログ (今後の追加予定)
- JSON形式でのデータインポート / エクスポート
- 軸ラベルのカスタマイズと複数マップのタブ切り替え
- アイテム詳細メモ機能

## ノンスコープ（やらないこと）
- サーバーサイド、データベースの構築
- ユーザー認証機能
- 複雑なレスポンシブ対応（PCブラウザでの利用を前提とする）

## 開発の始め方
```bash
bun install
bun run dev
```
