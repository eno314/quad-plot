# QuadPlot (クアッドプロット)

## 概要
あらゆる事象やアイディア、感覚を4象限（十字軸）に直感的にマッピングして視覚化するSPAツール。
コーヒーやワインなどの味覚の記録から、タスクの優先度整理、ポジショニングマップの作成など、特定の基準にとらわれず自由に要素をプロットし、全体を俯瞰するためのアプリケーションです。

## 技術スタック
- **Runtime / Package Manager**: Bun
- **Build Tool**: Vite
- **Language**: JavaScript (Vanilla JS)
- **Framework**: Alpine.js
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages (予定)

## 機能詳細

### 1. 4象限（十字軸）と自由なプロッティング
- 画面中央に配置された十字軸（X軸・Y軸）をベースに、直感的な操作で要素を自由にプロットできます。
- 画面上の任意の場所をダブルクリックするだけで、その位置に新しいアイテムを作成・配置できます。

### 2. アイテムの管理（名前・メモ・ドラッグ＆ドロップ）
- **追加・編集モーダル**: アイテムの追加時や、既存のアイテムをダブルクリックした際にリッチなモーダルダイアログが表示され、アイテムの名前と詳細なメモを記録できます。
- **ドラッグ＆ドロップ**: 配置したアイテムは、マウス操作で直感的にドラッグ＆ドロップして自由に位置を調整できます。

### 3. ラベルのフルカスタマイズ
- X軸・Y軸のプラス／マイナス表記（例: `(+)`, `(-)`）や、4つの象限ラベル（例: `Top Left`, `Bottom Right`）は、文字部分をダブルクリックすることで自由に任意のテキストに変更可能です。用途に合わせた専用のポジショニングマップを即座に構築できます。

### 4. マルチマップ（タブ切り替え機能）
- 画面上部のタブバーを使って、複数のマップを独立して作成・管理できます。
- 「新しいマップ」ボタン（`+`アイコン）からタブを追加でき、各タブ名はダブルクリックでわかりやすい名前に変更可能です。
- タブごとにアイテムや軸・象限ラベルの設定が独立して保存されます。

### 5. データの自動保存（ローカルストレージ）
- マップ上のすべての変更（アイテムの追加・移動・編集、タブの追加・名称変更、ラベルの変更など）は、ブラウザの `localStorage` に即座に自動保存されます。ページをリロードしても以前の状態からそのまま再開できます。

### 6. JSON形式でのデータインポート / エクスポート
- **エクスポート**: 画面右下の「エクスポート」ボタンから、現在の全タブ・アイテム・設定データをJSONファイルとして出力できます。プロンプトでファイル名を任意に指定できるほか、Web Share API に対応している環境ではOSネイティブの共有メニュー（AirDropやメール等）への転送も可能です。
- **インポート**: 「インポート」ボタンからPC上のJSONファイルを読み込み、過去のバックアップや別環境からのデータを復元できます（誤操作防止のため、上書き実行前に確認ダイアログが表示されます）。

## ノンスコープ（やらないこと）
- サーバーサイド、データベースの構築
- ユーザー認証機能
- 複雑なレスポンシブ対応（PCブラウザでの利用を前提とする）

## 開発の始め方
```bash
bun install
bun run dev
```
